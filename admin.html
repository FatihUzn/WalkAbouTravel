Öne Çıkan Turlar (Popular Trips)

Ana sayfada "OUR MOST POPULAR TRIPS" bölümünde gösterilecek turları seçin. En fazla 3 tur öne çıkarılabilir.

💡 İpucu: Bir turu "öne çıkan" yapmak için aşağıdaki tur listesinden ⭐ yıldız ikonuna tıklayın

Nasıl Kullanılır?

  1. Aşağıdaki formu Türkçe olarak doldurun
  2. 🌍 Otomatik Çeviri: "Otomatik Çevir" butonuna tıklayın
  3. 📸 Resim: Sadece dosya ismini yazın (örn: cappadocia.jpg)
  4. 📁 Yükleme: Resimleri cPanel → assets/ klasörüne yükleyin
  5. 💾 Kaydetme: "TÜMÜNÜ KAYDET" butonuna basıp JSON'u GitHub'a yükleyin

Resim Nasıl Yüklenir?

  1. Resim dosyasını hazırla (örn: cappadocia.jpg)
  2. Yukarıdaki alana sadece dosya ismini yaz
  3. cPanel → File Manager → assets/ klasörüne resmi yükle
  4. Otomatik path: assets/cappadocia.jpg

💡 İpucu: Dosya isimlerinde Türkçe karakter kullanma (ç→c, ğ→g, ı→i, ö→o, ş→s, ü→u)
